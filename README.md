# 맞춤법 키보드 (SpellKeyboard)

실시간 맞춤법 검사 + 더블탭 Shift 자동 교정 기능을 가진 안드로이드 커스텀 키보드(IME)입니다.

## 빌드 방법 (GitHub Actions)

1. 이 폴더를 GitHub 저장소로 push 합니다.
2. `Actions` 탭 → `Build APK` 워크플로우가 자동 실행됩니다 (push 시 자동, 또는 `workflow_dispatch`로 수동 실행 가능).
3. 완료되면 Actions 실행 결과 페이지 하단 `Artifacts`에서 `spell-keyboard-debug-apk`를 다운로드합니다.
4. 압축을 풀면 `app-debug.apk`가 나옵니다. 휴대폰으로 옮겨 설치하세요 (출처를 알 수 없는 앱 설치 허용 필요 — 이 역시 Android 보안 정책상 필수 단계입니다).

## 설치 후 사용법

1. 앱 실행 → `1. 키보드 활성화 설정 열기` → 목록에서 "맞춤법 키보드" 체크.
2. 앱의 `2. 키보드 전환` 버튼이나, 아무 텍스트 입력창을 길게 눌러 키보드 전환 → "맞춤법 키보드" 선택.
3. 아무 앱에서나 타이핑하면 됩니다.
   - 맞춤법 오류가 감지되면 키보드 위쪽에 카드가 뜨고, 오류 단어는 반투명 블루 하이라이팅 + 양 끝 텍스트커서 스타일로 표시됩니다.
   - `⇧` 키를 빠르게 두 번 탭하면 현재 제안된 교정이 바로 적용됩니다.
   - `⇧` 한 번 탭은 일반적인 대문자(쌍자음/이중모음) 전환입니다.

## 알아두면 좋은 점

- 맞춤법 검사는 부산대학교 한국어 맞춤법 검사기의 공개 결과 페이지를 호출하는 **온라인** 방식입니다 (키 설정 불필요하지만, 네트워크 연결 필요). 응답 포맷이 바뀌면 `SpellChecker.kt`의 `parseErrors()`만 수정하면 됩니다.
- Android 정책상 입력 필드 "내부"에 직접 하이라이팅을 그릴 수 없어, 하이라이팅/교정 UI는 키보드 영역 안의 제안 카드로 표시됩니다 (SwiftKey/Gboard 등 상용 키보드와 동일한 방식).
- 현재는 한글 자모(2벌식) + 스페이스/엔터/백스페이스만 지원하는 최소 구성입니다. 숫자/기호 키보드, 영문 키보드는 포함되어 있지 않습니다.
